## 口径铁律

1. **延迟只能取自 `cross_v6.json`**。其余批次是并发跑的，`contended=true` 已打进每条
   记录；把并发的 elapsed 与串行的比较，测的是调度不是系统。
2. **冗余调用判等用 `argh`（参数全量指纹），不用 `arg`**（80 字符截断的展示值）。
   旧记录无 `argh` 时会回落到 `arg`，其值偏高。
3. **重打分前先跑 `../tools/rescore_aggpick.py`**，它带一条不变量断言：判据未修改的
   任务重算必须逐位复现原值。该断言抓到过一次目录遮蔽（29 条记录会被静默替换）。
